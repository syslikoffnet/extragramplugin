# Local Snos

Плагин для **exteraGram / AyuGram** и других клиентов с той же Python-plugin системой.

Локально (только у тебя в клиенте) делает чужой аккаунт похожим на замороженный:

- имя → `удаленный аккаунт`
- аватарка пропадает
- появляется снежинка удалённого аккаунта
- в био — `Аккаунт заморожен`

На сервер Telegram ничего не уходит. Собеседник ничего не видит.

## Установка

Нужен **exteraGram 11+** / **AyuGram** с включёнными плагинами:
`Настройки → exteraGram / Plugins`.

### Через файл `.plugin` (проще всего)

1. Скачай [local_snos.plugin](https://github.com/syslikoffnet/extragramplugin/raw/arena/01a04044-extragramplugin/local_snos.plugin).
2. Отправь файл себе в **Избранное**.
3. Нажми на файл → **Установить плагин** → включи его.

### Вручную

Скопируй `local_snos.py` или `local_snos.plugin` в папку плагинов:

```
/data/user/0/com.exteragram.messenger/files/plugins/local_snos.py
/data/user/0/com.radolyn.ayugram/files/plugins/local_snos.py
```

## Как пользоваться

### Кнопка `hi` в профиле

1. Открой чужой профиль.
2. Нажми **⋮** (три точки).
3. Нажми **hi**.

Аккаунт локально станет «удалённым / замороженным».  
Повторное нажатие `hi` откатывает изменение. После сноса появляется bulletin с **Undo**.

Та же кнопка есть в меню чата (⋮ в переписке).

### Команда в любом чате

Сообщение **не отправляется** собеседнику — плагин перехватывает его и отменяет отправку.

```
.snos 123456789
.snos @username
.snos username
.snos https://t.me/username
.snos "username"
```

В личке можно без аргумента — сносится собеседник текущего чата:

```
.snos
```

Откат из чата:

```
.unsnos @username
.unsnos 123456789
.unsnos
```

Если указан числовой id, пользователь должен уже быть в кэше клиента (открой профиль хотя бы раз). По `@username` плагин резолвит через Telegram API.

## Настройки плагина

`Plugins → Local Snos`:

| Пункт | Зачем |
| --- | --- |
| Включить локальный снос | Временный выключатель. Список скрытых сохраняется |
| Команда `.snos` в чатах | Можно выключить перехват команд |
| Локальное имя | По умолчанию `удаленный аккаунт` |
| Текст «заморозки» | По умолчанию `Аккаунт заморожен` |
| Список скрытых | Нажми на человека, чтобы вернуть как было |
| Восстановить всех | Откатить весь список |

## Что именно меняется

Плагин не банит и не удаляет аккаунт. Он:

1. Сохраняет оригинальные имя, username, флаги, фото и био.
2. В памяти клиента ставит `user.deleted = true`, убирает фото и username.
3. Подменяет отображаемое имя и about.
4. Не даёт апдейтам с сервера вернуть настоящий вид, пока аккаунт в списке.
5. В SQLite пишет **оригинальные** данные, чтобы после перезапуска клиента можно было корректно откатиться.

Снежинка — штатная иконка удалённого аккаунта в Telegram (`AvatarDrawable.drawDeleted` / `UserObject.isDeleted`).

## Совместимость

- exteraGram 11.0.0+ с plugin SDK `>= 1.4.3.10`
- AyuGram и форки на той же plugin-системе
- Несколько аккаунтов в одном клиенте

## Важно

Это **только визуальный локальный эффект**.  
Он не «сносит» человека в Telegram, не блокирует его и не мешает ему писать. Если выключить плагин, настоящие имя и аватарка возвращаются сразу.
