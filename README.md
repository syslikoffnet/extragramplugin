# Local Snos

Плагин для **exteraGram / AyuGram** и других клиентов с той же Python-plugin системой.

Локально (только у тебя в клиенте):

- делает чужой аккаунт похожим на замороженный
- добавляет на **свой** профиль обычные подарки и улучшает их до коллекционных NFT

На сервер Telegram ничего не уходит. Собеседник ничего не видит. Настоящие подарки плагин не продаёт и не трогает.

## Установка

Нужен **exteraGram 11+** / **AyuGram** с включёнными плагинами:
`Настройки → exteraGram / Plugins`.

### Через файл `.plugin` (единственный рабочий способ)

1. Скачай [local_snos.plugin](https://github.com/syslikoffnet/extragramplugin/raw/arena/01a04044-extragramplugin/local_snos.plugin).
2. Отправь файл себе в **Избранное**.
3. Нажми на файл → **Установить плагин** → включи его.

Не открывай `local_snos.py` как документ и не кидай `.py` в папку плагинов вручную — ExtraGram тогда грузит файл без SDK и падает с `No module named 'base_plugin'`. Если уже так сделал: удали плагин в настройках, удали `local_snos.py` из папки plugins, поставь только `.plugin`.

## Как пользоваться

### Кнопка `hi` в профиле

1. Открой чужой профиль.
2. Нажми **⋮** (три точки).
3. Нажми **hi**.

Аккаунт локально станет как настоящий frozen/deleted: Telegram сам рисует HiddenName и снежинку.  
Повторное нажатие `hi` откатывает изменение. После сноса появляется bulletin с **Undo**.

Та же кнопка есть в меню чата (⋮ в переписке).

### Команда в любом чате

Сообщение **не отправляется** собеседнику — плагин перехватывает его и отменяет отправку.

```
.snos 123456789
.snos @username
.snos username
.snos https://t.me/username
.snos "username"
```

В личке можно без аргумента — сносится собеседник текущего чата:

```
.snos
```

Откат из чата:

```
.unsnos @username
.unsnos 123456789
.unsnos
```

Если указан числовой id, пользователь должен уже быть в кэше клиента (открой профиль хотя бы раз). По `@username` плагин резолвит через Telegram API.

## Настройки плагина

`Plugins → Local Snos`:

| Пункт | Зачем |
| --- | --- |
| Включить локальный снос | Временный выключатель. Список скрытых сохраняется |
| Команда `.snos` в чатах | Можно выключить перехват команд |
| Список скрытых | Нажми на человека, чтобы вернуть как было |
| Восстановить всех | Откатить весь список |
| Показывать на своём профиле | Локальные подарки во вкладке «Подарки» |
| Добавить подарок | Категории каталога (Pepe, духи, жабы, книги, ручки…) → на свой профиль |

## Локальные подарки

Свой профиль → ⋮ → **Подарки** (или настройки плагина).

1. Поиск по названию или список **всех улучшаемых** (неулучшенные базы, включая sold out): Pepe, духи, жабы, книги, ручки.
2. Подарок **добавляется** во вкладку «Подарки» рядом с уже имеющимися — настоящие подарки не заменяются. После добавления список остаётся открытым, можно выбрать ещё.
3. Тапни → **Улучшить**. Откроется обычный экран Telegram с анимацией подбора модели, фона и узора. Подтверди — подарок станет коллекционным 1:1, Stars не списываются.

Настоящие подарки плагин не продаёт и не трогает. Продажа / перевод / вывод локальных NFT отключены.

## Что именно меняется

Плагин не банит и не удаляет аккаунт. Он:

1. Сохраняет оригинальные имя, username, флаги, фото и био.
2. В памяти ставит `user.deleted = true`, убирает фото и username.
3. Имя в шапке: `❄ удаленный аккаунт`. Под именем, в поле статуса (не в описании): `Аккаунт заморожен`.
4. Описание / «О себе» очищается, как у настоящего frozen/deleted.
5. Не даёт апдейтам с сервера вернуть настоящий вид, пока аккаунт в списке.
6. В SQLite пишет **оригинальные** данные, чтобы после перезапуска можно было откатиться.

Снежинка в аватарке — штатная иконка удалённого аккаунта (`AvatarDrawable.drawDeleted`). Снежинка перед именем — как у настоящего frozen.

## Совместимость

- exteraGram 11.0.0+ с plugin SDK `>= 1.4.3.3`
- AyuGram и форки на той же plugin-системе
- Несколько аккаунтов в одном клиенте

## Важно

Это **только визуальный локальный эффект**.  
Он не «сносит» человека в Telegram, не блокирует его и не мешает ему писать. Если выключить плагин, настоящие имя и аватарка возвращаются сразу.
